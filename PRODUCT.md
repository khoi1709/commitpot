# CommitPot

## Product purpose

Attendance commitment funds for university study groups, workshops and community events: deposit Test USDC, attend, receive the recorded entitlement. Financial rules are immutable and on-chain; a named human verifier remains trusted for attendance.

## Platform and users

Web application using Next.js, TypeScript, Tailwind and wagmi/viem. Solidity/Foundry contracts target Avalanche Fuji, chain43113. Organizers create pots; participants deposit/check in/claim; verifiers sign per-wallet EIP712 proofs. Local mock mode is explicitly labelled; local-chain integration precedes any separately authorized testnet release.

## Scope

Create pot, exact-amount approval/deposit, personal QR, verifier scan/manual fallback, attendance signature and transaction, permissionless finalization, beneficiary-safe pull payout, receipts and recovery. Complete zero-attendance refund and deterministic dust rules. No mainnet, real money, fees, admin withdrawal, mutable rules, proxy upgrade, yield, proprietary token, AI judging, database, or claim that cryptography proves real-world presence.

Task-first rather than trading-dashboard decoration. Plain financial rules, clear deadlines/timezones, exact token amounts distinct from gas, receipt-confirmed outcomes. Camera denial has a manual path. Read-only information without wallet connection. Keyboard focus, readable copy, labelled state not color alone, reduced motion and mobile usable controls.
