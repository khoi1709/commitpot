# CommitPot operational interface

Mode: Operate. Code-led. Users open an event, commit a fixed deposit, check in and retrieve their exact entitlement. EN/VI is a direct human requirement; the human explicitly delegated visual choice and implementation, so the following is a lead-selected direction, not fabricated user preference.

## Grounded direction choice

Seven grounded candidates: university event notices; contemporary cooperative identity; museum membership programmes; community-run sports clubs; festival volunteer wayfinding; municipal recreation programmes; student association membership graphics. Assigned candidate7 selected under delegated choice: association graphics with clear blue-violet identity, white working surfaces, compact neutral sans and a strong status/accountability vocabulary. No ticket-paper costume or trading dashboard.

Challengers considered: type specimen competitive on hierarchy but weak on event context; orienteering competitive on state clarity but weak on financial context; catalog sleeve declined on legibility (raise explicit state hierarchy); reference setting declined for phone use (raise disciplined measures); airline wallet competitive for lifecycle but risks costume; warm consumer app competitive for familiarity but weaker event identity (raise plain-language action clarity). None beats both product clarity and audience fit. No challenger imagery adopted.

## Direction contract

THESIS: An event commitment is understandable before a wallet prompt; refuse decorative DeFi charts and promises of guaranteed yield.

OWN-WORLD: White and cool-lilac working surfaces, saturated indigo brand rail/header, dark ink, lime confirmation only where backed by state. Workhorse sans, generous readable numbers and native labelled controls.

STORY: Read fixed rules, commit, attend, collect. A visible three-stage event rail explains registration, attendance and settlement. Mock mode is unmistakeable.

FIRST VIEWPORT: Product/language controls above an event list and main event workspace. Event phase and exact deposit lead; personal status/action occupies a separate right panel, stacking first on phones. A check-in ledger links confirmed attendance to the eventual split.

FORM: Grounded candidate7, student association membership identity, translated only through palette/type/density/one lifecycle signature, not physical artifact controls. seed:e6835f7997a9b172. Chosen by lead under direct human delegation.
